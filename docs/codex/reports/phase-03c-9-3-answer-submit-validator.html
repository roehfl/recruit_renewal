Submit Rule

Required Questions

  • Active required=true question with no answer row fails.
  • Null answerText fails.
  • Blank answerText fails.
  • Failure uses existing InvalidJobApplicationException.
Preserved

Optional Questions

  • required=false questions may be unanswered.
  • Null or blank optional answers pass submit.
  • Length limits still apply to non-null answers.

Validation Policy Table

minLengthDeferredStored but not enforced yet.

Submit Flow

  1. Find applicant-owned application.
  2. Run existing DRAFT, posting status, reception period, and form config checks.
  3. Run ApplicationSubmitValidator.validate(application).
  4. Only after validation passes, set submitted state and time.

Not Implemented

  • Admin answer lazy read API
  • Applicant answer-only GET API
  • Choice/file answer domains
  • Attachment linkage
  • QuestionSet
  • StageResult
