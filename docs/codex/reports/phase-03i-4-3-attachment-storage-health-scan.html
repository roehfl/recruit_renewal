Phase 03i-4-3 Attachment Storage Health Scan Dry-Run

Shinyoung Recruit Backend Renewal · Generated/updated: 2026-05-20

Executive Summary

Implemented an admin dry-run scan for attachment storage health. The scan compares retained attachment rows with local physical files and reports mismatches without deleting files or changing DB state.

The phase also improved physical delete observability with a structured delete result while preserving the existing delete API response contract.

Domain / Entity Structure

ApplicationAttachment remains the retained attachment lifecycle row under JobApplication. The scan reads STORED, DELETED, and MISSING rows, and excludes METADATA_ONLY.

No entity relationship, schema, or lifecycle status is mutated by the scan.
