Phase 08e · CERTIFICATE Funnel Dimension 완료

요약

07c funnel 통계에 CERTIFICATE dimension을 추가했다. 자격명(free-text)을 정규화(trim+공백 압축)해 자격명별 보유 지원자 distinct로 그룹화한다. SCHOOL/POSITION과 달리 그룹이 중복(한 지원자가 여러 자격 보유 시 여러 그룹)될 수 있고, topN(기본 10) 초과 자격 보유자는 '기타'로 합산한다. 무보유 지원자는 미포함. 테스트 BUILD SUCCESSFUL.

로직

항목규칙
그룹 키자격명 정규화(trim + 내부 공백 압축). 빈 자격명 제외.
그룹해당 자격 보유 지원자 distinct(P 내). 중복 허용(한 지원자 여러 그룹) → 그룹 합 ≠ |P| 가능.
topN보유자 수 desc·이름 asc, 기본 10(최대 100, 0/null→10) 개별. 초과 자격 보유자 distinct = '기타'.
무보유자격 없는 지원자는 어느 그룹에도 미포함(보유 의미).
응답기존 DimensionFunnelResponse 재사용. CERTIFICATE: groupId=null/groupName=정규화 자격명, 기타=null/"기타".
audit없음(집계값만, 자격명 비민감).

API

MethodPath접근Purpose
GET/api/admin/job-postings/{id}/statistics/funnel?dimension=CERTIFICATE&topN=admin자격별 funnel(보유 지원자 distinct + '기타')

dimension: 미지정=overall, POSITION/SCHOOL/CERTIFICATE 지원, 그 외 값=400. topN은 SCHOOL/CERTIFICATE에 적용.

테스트

명령: $env:AES_SECRET_KEY='...'; .\gradlew.bat test --tests "*AdminStatisticsControllerTest" --no-daemon
결과: BUILD SUCCESSFUL — 기존 + SCHOOL 5 + CERTIFICATE 2 통과.

자격명별 distinct + 정규화(trailing space 병합) + 중복 집계(app1=정보처리기사·TOEIC)/무보유 제외, topN=1 → '기타' 합산. unsupported는 잘못된 값으로 변경. overall/POSITION/SCHOOL 회귀 비파괴.
