Phase 07e · Application PDF 완료

신영증권 채용 Renewal 백엔드 · admin 전용 · Thymeleaf + openhtmltopdf · 생성일 2026-06-02

요약

운영자가 지원자 1명의 지원서를 PDF 1개로 출력한다. Thymeleaf XHTML → jsoup 정규화 → openhtmltopdf(PDFBox)로 렌더하고, applicant free-text는 th:text만 사용(HTML injection 차단), 외부 resource를 로드하지 않으며 CJK 폰트를 resources에 번들해 임베드한다(시스템 폰트 없이도 한글 출력). ci/ciHash/password는 어디에도 포함하지 않고, 생성 시 audit를 남긴다. 테스트 BUILD SUCCESSFUL(3건).
