요약

운영자가 지원자 1명의 지원서를 PDF 1개로 출력한다. Thymeleaf XHTML → jsoup 정규화 → openhtmltopdf(PDFBox)로 렌더하고, applicant free-text는 th:text만 사용(HTML injection 차단), 외부 resource를 로드하지 않으며 CJK 폰트는 번들 시 임베드한다. ci/ciHash/password는 어디에도 포함하지 않고, 생성 시 audit를 남긴다. 테스트 BUILD SUCCESSFUL(3건).
