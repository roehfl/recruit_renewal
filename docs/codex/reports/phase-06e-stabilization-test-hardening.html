요약

Phase 06e는 면접 평가 기능의 회귀/안정화 테스트 slice입니다. 운영 코드 변경 없이(테스트 전용) 경로를 교차로 검증하는 회귀 테스트를 추가합니다.

특히 06d 리뷰에서 요청한 StageResult 비변경 회귀 테스트(실제 StageResult row를 만들어 submit/reopen/read 전후 불변 검증)를 실행 가능한 테스트로 고정합니다.

이로써 Phase 06(면접 평가) 06a~06e가 모두 완료됩니다.

StageResult 비변경 회귀

회귀 고정 실제 PENDING StageResult row를 생성한 뒤 평가 submit / reopen / 조회(면접·단계·지원서)를 수행하고, StageResult가 불변임을 단언합니다.

StageResult(initialize) = PENDING, score=null, comment=null, decidedAt=null
   ├─ interviewer submit   → StageResult 불변
   ├─ admin reopen         → StageResult 불변
   └─ admin read (3종)     → StageResult 불변
row count == 1 유지

향후 평가 동작이 StageResult를 건드리도록 바뀌면 이 테스트가 실패하여 경계 위반을 즉시 잡습니다.
