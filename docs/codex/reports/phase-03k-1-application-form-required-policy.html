Phase 03k-1 - Public Application Form Required Policy

공개 채용공고 목록/상세 응답에 지원서 섹션별 필수/선택 정책을 읽기 전용으로 추가했다.

Completed Generated: 2026-05-22 Source: docs/codex/implementation/phase-03k-1-application-form-required-policy.md

Executive Summary

지원자 공개 공고 API에 applicationFormRequiredPolicy를 추가했다. 정책은 현재 제출 검증과 동일하게 기존 useXxx 플래그와 활성 질문의 required 값을 읽어서 계산한다.

DB, Entity, 관리자 요청/응답, 최종 제출 검증, 대시보드 완료 판단은 변경하지 않았다. 공개 목록에서는 질문 수를 배치 집계해 목록 크기만큼 질문 count 쿼리가 반복되지 않도록 했다.

Phase 03k 설계의 target requireXxx 모델은 아직 구현하지 않았다. 이번 단계는 instruction.md가 요구한 공개 read-only compatibility slice다.
