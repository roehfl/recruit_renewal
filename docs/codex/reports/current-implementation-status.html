Status Snapshot Generated: 2026-05-19

요약

현재 백엔드는 채용 공고, 전형 단계, 지원서 작성/제출, 지원서 상세 섹션, 질문/답변, 전형 결과 관리의 주요 vertical slice가 구현된 상태입니다.

최근 작업 기준으로 StageResult는 관리자 초기화/조회/수정/일괄수정, 관리자 지원서 상세 timeline, 지원자 결과 조회, 발표 후 정정 이력까지 구현되어 있습니다.

운영 전 남은 핵심 축은 인증/인가 hardening, 실제 관리자 identity 전파, 메시지/알림, 면접/평가, 엑셀/PDF/통계/파기 기능입니다.

남아있는 주요 작업

우선순위영역남은 작업권장 다음 단계
1 보안/권한 SecurityConfig의 개발용 permitAll 제거, /admin/**와 /applications/** 접근 제어, 401/403 JSON 응답 Phase 03e-2, 03e-3, 03e-4 순서로 구현
2 관리자 identity StageResult update/correction의 SYSTEM actor를 실제 임직원/admin loginId 또는 audit actor로 교체 CurrentEmployeeService 또는 CurrentAdminService 추가
3 LDAP/운영 설정 운영 profile 기준 LDAP property 외부화, role mapping 값 확인, public endpoint allowlist 확정 보안 hardening 구현 전 설정 정책 확정
4 면접/평가 면접 일정/조, 면접 참여자, 면접관 평가, 평가 결과와 StageResult 연동 Interview vertical slice 설계/구현
5 메시지/알림 합격/불합격 안내, 정정 알림, SMS/Email/알림톡 발송 이력 MessageBatch/MessageSendLog 구현
6 파일 실물 처리 현재 첨부파일은 metadata 중심이며, 실제 multipart 업로드/다운로드/저장소 연동은 남음 Attachment storage phase 분리
7 엑셀/PDF/통계 지원자 목록/전형결과 엑셀, 지원서 PDF, 지원율/합격률 통계 core CRUD 안정화 후 별도 reporting/export phase
8 개인정보 파기/감사 지원자 개인정보 파기 정책, 접근 감사 로그, 민감정보 masking/권한 세분화 보안 hardening 이후 audit/privacy phase

  • 현재 작업트리에는 여러 Phase의 미커밋 변경이 함께 존재합니다. 이 문서는 그 상태를 기준으로 작성한 현황 요약입니다.
