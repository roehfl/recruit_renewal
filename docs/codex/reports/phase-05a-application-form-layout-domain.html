Domain Structure

Entity Relationship

JobPosting 1 --- N ApplicationFormPage
ApplicationFormPage 1 --- N ApplicationFormPageItem
ApplicationFormPageItem N --- 1 ApplicationSectionType enum value

Data Ownership

  • ApplicationFormPage is owned by JobPosting.
  • ApplicationFormPage owns item rows with cascade and orphan removal.
  • ApplicationFormPageItem.sectionType stores an enum string.
  • Layout rows do not own applicant answer, attachment, or section detail data.
