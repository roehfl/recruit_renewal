요약

폐쇄망 로컬 LLM 에이전트가 AGENTS.md → docs/domains/_index.md → 도메인 카드 1~2개만 읽고 유지보수할 수 있도록 문서를 재편했습니다. 설계서(local-llm-docs-restructure_design.html)의 구조를 그대로 구현했습니다.

도메인 카드 15개를 현재 코드 기준으로 작성하고, 카드마다 독립 리뷰어가 코드와 대조 검증했습니다. 컨트롤러 매핑 201개와 카드 API 표 행 수가 전 카드에서 일치합니다.

이력 문서 약 240개는 docs/archive/로 옮겼고(git mv, 이력 보존), 점검 스크립트 tools/check-docs.mjs가 경로·소유·크기를 검사합니다. 코드는 한 줄도 수정하지 않았습니다.

카드 작성 중 코드 결함 후보, 계약·코드 불일치, 폐쇄망 운영 위험을 다수 발견해 아래에 정리했습니다. 문서 재편분은 main에 커밋·푸시했습니다.

폐쇄망·보안 관련 주의

  • 폐쇄망 주소 입력칸(우편번호·기본주소)이 읽기 전용이라, 외부 주소 API(juso.go.kr)가 막히면 지원자가 주소를 입력할 수 없음. 학교 검색도 외부 API(NEIS·대학 OpenAPI) 단일 출처, 대체 없음.
  • 운영 DDL 면접 종료시각 제거(9baaeef)에 따른 interview.end_date_time 컬럼·idx_interview_time_range 인덱스 삭제 SQL이 recruit_back/recruit_backend/docs/ops/에 없음.
  • 보안 /api/admin/role-mappings/** 전용 매처가 없어 ROLE_RECRUIT_ADMIN이 자신에게 ROLE_PRIVACY_ADMIN을 매핑할 수 있음(ADR 0007 직무 분리 우회 가능, 설계 승인 사항이었음).
  • 보안 메뉴 관리 매처 /api/menu/admin/menu/*가 경로 한 단계만 보호 — 하위 쓰기 경로 추가 시 비인증 노출 위험.
  • 보안 NICE 목업이 매번 임의 CI를 생성해 CI 해시 기반 중복 가입 차단이 사실상 동작하지 않음.
