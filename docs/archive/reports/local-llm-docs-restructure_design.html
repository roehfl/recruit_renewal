신영증권 채용 Renewal (recruit 모노레포)

로컬 LLM 유지보수용 문서 재편 설계

설계 완료 작성일: 2026-09-18

요약

폐쇄망 반입 뒤 로컬 LLM 에이전트(컨텍스트 최대 180K)가 유지보수할 수 있도록 프론트·백엔드 문서를 도메인별 통합 카드 체계로 재편하는 설계입니다.

레이어별 패키지 구조에 맞춘 문서는 기능 하나를 고칠 때 여러 문서를 오가야 해서 채택하지 않았습니다. 카드 1개에 API 계약, 백엔드 파일 지도, 프론트 파일 지도, 규칙, 변경 레시피를 함께 담습니다.

AGENTS.md를 정본 진입점으로 삼고, 이력성 문서는 docs/archive/로 격리하며, 문서와 코드의 불일치는 점검 스크립트로 잡아냅니다.

작업 순서는 공통 골격 → 카드 15개 → archive 이동과 링크 정리 → 전체 점검입니다.

결정 로그

#결정근거
1패키지(레이어)별이 아닌 도메인별 문서백엔드가 레이어별 평면 구조라서 기능 하나가 모든 레이어를 가로지름
2프론트·백엔드 분리 대신 도메인 통합 카드약한 모델이 문서 3개 동기화에서 누락하기 쉬움. 화면 슬라이스 워크플로우와 같은 모양
3AGENTS.md를 정본으로, CLAUDE.md는 @AGENTS.md import로컬 에이전트 도구의 사실상 표준. 백엔드의 AGENTS/CLAUDE 중복 해소
4카드는 현재 코드 기준으로 작성02-domain-design 등 옛 설계가 현재 코드와 다름
5이력 문서는 삭제하지 않고 git mv로 archive이력 보존과 검색 잡음 제거를 함께 달성
6경로 접두 표기 {BE} 등 도입긴 백엔드 경로를 반복하는 토큰 비용 절감. 점검 스크립트가 확장
7점검 스크립트에 소유 커버리지 검사 포함새 컨트롤러·화면을 추가하고 카드를 갱신하지 않는 누락을 기계적으로 검출
8문서 읽기 총량은 컨텍스트의 25% 이하로컬 모델은 긴 컨텍스트에서 성능이 떨어지므로 코드와 추론 여유를 확보
