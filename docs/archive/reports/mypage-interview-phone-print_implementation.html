마이페이지 보완·지원서 인쇄 - 구현 결과

구현 완료 작성일: 2026-09-27

요약

API는 있었지만 화면이 없던 기능 3개를 붙이고, 점검에서 찾은 작은 결함 2개를 고쳤습니다.

지원자 마이페이지에 면접 일정 조회와 휴대폰 번호 변경을 넣었고, 관리자 지원현황의 "인쇄"는 선택 지원서를 합본 PDF로 받아 바로 인쇄 대화상자를 여는 방식으로 구현했습니다.

지원 철회 화면은 만들지 않기로 결정했습니다.

완료

  • 가입 화면 "인증 완료" 버튼 disable 오타 → disabled

  • 실제 브라우저에서 인쇄 대화상자가 뜨는 것(앱 내 브라우저에서는 iframe 로드·인쇄 호출 직전까지 확인)

  • 서버 쪽 휴대폰 번호 형식 검증(화면에서만 확인)

검증 및 비즈니스 규칙

인쇄

규칙설명
내용각 지원서는 단건 PDF와 같고, 합본은 선택 순서대로 이어 붙인다
상한·권한·감사일괄 zip과 같음: 20건, 관리자+임직원 세션, 합본을 다 만든 뒤 건별 APPLICATION_PDF 감사 → 스트리밍
진행 표시클릭부터 인쇄 대화상자까지 닫을 수 없는 진행 창: 단계(PDF 만들기 → 인쇄 창 열기), 흐르는 막대, 경과 초. 실제 %는 서버가 다 만든 뒤 보내 알 수 없음. 20초 안에 못 열면 안내
메모리건별 PDF를 temp 파일로 쓰고 PDFBox 합치기도 temp 파일 버퍼 사용, 조각 파일은 항상 삭제
즉시 인쇄PDF를 보이지 않는 iframe(크기 0)에 불러와 로드되면 print()로 인쇄 대화상자를 연다. 새 탭을 쓰지 않아 팝업 차단과 무관하고, iframe은 다음 인쇄나 화면 이탈 때 정리

면접 일정·휴대폰 번호

규칙설명
면접 일정 칸지원서에 면접이 있으면 [확인] + 취소되지 않은 가장 이른 일시, 모두 취소면 "취소됨", 없으면 "-"
일정 모달단계·면접 일시·도착 시간·방식·장소(호실)·온라인 링크, 취소 면접은 취소선과 태그
번호 형식숫자만 남겨 ^01[016789]\d{7,8}$ 확인 후 숫자만 전송

결정 로그

#결정근거
1지원 철회 화면은 만들지 않음사용자 결정
2인쇄 = 선택 지원서 합본 PDF로 바로 인쇄 대화상자사용자 요청(파일 받지 않고 인쇄까지). zip은 인쇄할 수 없어 합본 API 추가, 새 탭 PDF 보기는 스크립트 인쇄가 불안정해 숨은 iframe 사용
3PDF 합치기는 기존 라이브러리가 포함한 PDFBox 사용새 의존성 추가 금지 규칙
4번호 변경은 비밀번호 확인만사용자 결정, 기존 API 그대로
