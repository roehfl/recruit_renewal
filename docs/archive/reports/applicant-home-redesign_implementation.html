구현 완료 프론트 단독 · API 무변경 폰트 · 로고 교체 포함 작성일: 2026-08-26

요약

지원자 홈 화면을 확정 시안에 맞춰 재구성했다. 지원자 영역의 프레임 폭을 전체의 85%로 좁히고, 헤더·본문·푸터를 같은 폭으로 정렬했다.

본문은 좌측 진행중인 채용공고(1/2) + 우측 퀵링크 카드 6장(3×2, 1/2)의 2컬럼 구조이며, 우측 카드 블록이 좌측 카드 높이를 채워 어느 화면 폭에서든 하단 라인이 맞는다.

푸터는 높이 56px로 고정하고 화면 하단에 항상 떠 있도록(position: fixed) 변경했다. 홈 채용공고 노출은 상위 4건으로 제한했다.

본문 폰트를 Pretendard에서 Noto Sans CJK KR로 교체하고 자체 호스팅했으며, 헤더 로고를 CI 이미지 + '신영증권' 텍스트 조합으로 변경했다.

프레임 바깥은 회색(--app-bg-page)으로 깔고, 헤더+본문+푸터를 아우르는 1px 윤곽선을 넣어 프레임 경계를 드러냈다.

백엔드 API 요청/응답은 건드리지 않았으므로 api-contract.md 영향은 없다.

좌측 공고 카드 높이는 글자 기반으로 고정이고, 우측 카드 높이는 행 균등 분할로 좌측 높이를 따라간다. 그 결과 화면 폭과 무관하게 좌·우 하단이 일치한다. 다만 카드가 정사각형은 아니며, 폭이 넓어질수록 가로로 길어진다.

결정 로그

#결정근거
1 프레임 폭을 각 화면이 아니라 --app-frame-width 토큰에서 변경 지원자 화면 15곳이 이미 이 토큰을 참조하고 있어 한 곳 수정으로 전체가 일관되게 적용된다
2 헤더 배경 바까지 85%로 제한 원래는 배경만 풀블리드였으나, 본문과 시각적으로 어긋난다는 지적에 따라 바 전체를 프레임에 맞췄다
3 카드 정사각형(aspect-ratio: 1/1) 포기 좌측 높이는 고정이고 정사각 카드 높이는 폭에 비례하므로 특정 폭에서만 하단이 맞는다. 하단 정렬을 우선했다
4 홈 공고 노출을 4건으로 제한 6건이면 좌측이 과도하게 길어져 우측 카드가 세로로 늘어진다. 전체 목록은 '바로가기'로 이동 가능하다
5 푸터를 sticky가 아니라 position: fixed로 "항상 떠 있어야 한다"는 요구에 맞춰 스크롤과 무관하게 화면 하단에 고정했다
6 라우트 없는 카드도 의도한 경로를 그대로 기재 경로를 비워두면 화면 준비 시 다시 찾아야 한다. TODO 주석으로 미존재 사실을 명시했다
7 Noto Sans KR을 CDN이 아닌 self-host로 기존 Pretendard도 self-host였고, 사내망에서 외부 CDN 차단 시 폰트가 깨지지 않도록 했다
8 정적 weight 4종(496 서브셋)이 아니라 가변 폰트(124 서브셋)로 파일 수가 1/4로 줄고 100~900 전 굵기를 커버한다. 총 3.36MB
9 CI를 드롭인 슬롯(public/images/ci.*)으로 구현 header-logo·main-banner와 동일한 기존 패턴이다. 파일만 넣으면 코드 수정 없이 적용된다
10 Pretendard woff2 파일은 삭제하지 않고 보존 자산 삭제는 되돌리기 어렵다. @font-face 정의만 제거해 실제 로드는 발생하지 않는다
11 윤곽선을 레이아웃 전체가 아니라 .applicant-frame 래퍼에 부여 바깥 회색 영역과 안쪽 흰 프레임을 분리해야 한다. 고정 푸터는 프레임 밖으로 빠지므로 좌우 테두리를 따로 줘 선을 이었다
12 본문 높이를 calc(100vh - 72px - ...)에서 flex로 전환 헤더 실제 높이가 border 포함 73px이라 계산식이 2px 어긋나 스크롤이 생겼다. flex 컬럼으로 바꿔 매직넘버를 제거했다
13 이중 85% 문제를 15개 화면 수정이 아니라 CSS 변수 재선언으로 해결 지원자 화면 15곳이 max-width: var(--app-frame-width)를 쓴다. .applicant-content에서 토큰을 100%로 재선언하면 상속으로 전부 해결되고, 프레임과 푸터는 바깥 스코프의 85%를 그대로 쓴다

미결 사항

#질문현재 입장
1 신영증권 소개 / 채용 FAQ 화면을 새로 만들 것인가, 외부 링크로 연결할 것인가? 미정. 결정 후 applicantRoutes.ts에 추가하거나 카드 url을 외부 URL로 교체한다
2 /apply, /my/result 라우트를 이번 기회에 정리할 것인가? 기존 값을 보존했다. 별도 승인 시 정리한다
3 카드 설명 문구를 확정 문안으로 교체할 것인가? 현재 문구는 임시안이다. 특히 '신영증권 소개', '채용 FAQ' 두 건은 새로 작성한 문구다
4 공고 목록 API 실패 시 방어 코드를 추가할 것인가? 기존 결함이며 이번 범위 밖으로 두었다. 별도 작업으로 처리 권장
5 1440px 이하 좁은 화면에서 카드 비율이 세로로 길어지는 것을 허용할 것인가? 하단 정렬을 우선한 결과다. 문제가 되면 폭 구간별로 카드 배치(3×2 → 2×3)를 바꾸는 방안이 있다
6 99 × 102 규격의 실제 CI 파일은 언제 반영하는가? 미제공 상태다. 현재는 src/assets/images/logo.png(485 × 576)가 폴백으로 표시되며, 99 : 102 박스에 object-fit: contain으로 들어가 좌우에 약간의 여백이 생긴다
