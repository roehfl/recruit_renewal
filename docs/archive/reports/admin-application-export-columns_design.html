설계 완료 작성일: 2026-09-18

요약

지원현황 조회의 엑셀 다운로드에 컬럼 선택 모달을 추가합니다. 관리자는 지원자 정보 44개 항목 중 원하는 것만 체크해 내려받습니다.

컬럼 카탈로그는 백엔드 ApplicationExportColumn enum이 단일 출처이며, 모달은 카탈로그 조회 API 응답으로 체크박스를 렌더합니다. 항목 추가·삭제는 enum 한 곳만 고치면 됩니다.

1행 = 1지원자를 유지하고, 학력·경력 등 1:N 정보는 섹션당 한 셀에 줄바꿈으로 요약합니다. 자기소개서는 제외합니다.

지원현황 화면 결함 2건(철회 라벨, 졸업년월 컬럼)을 함께 수정합니다. 구현은 백엔드 → 프론트 2개 slice로 나눕니다.

결정 로그

#결정근거
11:N 정보는 섹션당 한 셀 줄바꿈 요약1행 = 1지원자 유지로 Excel 필터·정렬이 쉬움. 번호별 펼침은 컬럼 폭증
2자기소개서 제외PDF로 열람. 엑셀 셀에 부적합한 장문
3카탈로그는 백엔드 enum 단일 출처 + 조회 API라벨 이중 관리 방지. 과거 목록/export 필터 불일치 결함과 같은 유형 재발 방지
4모달 오픈 시 매번 기본 컬럼으로 시작사용자 선택. 선택 기억 저장소 불필요
5columns는 검색 조건 DTO와 분리된 @RequestParam목록 조회 요청 오염 방지
6선택 컬럼이 요구하는 섹션만 페이지 배치 조회기본 선택 시 불필요한 1:N 조회 회피, N+1 없음
7이름·휴대폰·이메일은 PDF와 같은 원천 규칙같은 지원자에 대해 PDF와 엑셀 값이 어긋나지 않게 함
8최종학력·최신 전형 비교 규칙은 인라인 + 동기화 주석기존 관례 준수, 인접 코드 리팩터링 없음
9면제·미필 사유와 자격증번호는 엑셀에서 제외관리자 화면·PDF에서도 마스킹되는 값 — 엑셀로만 평문 반출하면 기존 정책과 어긋남
10값 표기는 PDF와 동일하게 맞춤같은 지원자를 PDF와 엑셀에서 다르게 보이지 않게 함. 기존 헬퍼 규칙 재사용
