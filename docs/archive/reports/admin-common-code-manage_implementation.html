요약

설계서(2026-08-28-admin-common-code-manage-design.md)대로 관리자 공통코드 관리 화면 /admin/codes를 구현했다. 신규 2개 파일, 수정 3개 파일이며 백엔드는 전혀 건드리지 않았다.

그룹은 CODE_GROUP 자기참조 구조로 관리하고, 그룹 행의 description이 사용 화면 메모로 화면 상단에 노출된다. 삭제는 active=false soft delete뿐이며 비활성화 시 확인 모달이 그룹 성격에 따라 다른 경고를 띄운다.

npm run type-check와 npm run build가 모두 통과했다. 실제 데이터 흐름을 확인하는 수동 시나리오는 백엔드 기동과 관리자 계정이 필요해 아직 수행하지 못했다.

구현 상세

상태와 파생

  • codes — 전체 코드 1회 조회 결과를 메모리에 보관
  • groupRows — groupCode === CODE_GROUP 행
  • groupOptions — 등록 그룹 + 데이터에만 있는 미등록 그룹
  • rows — 선택 그룹 · 비활성 필터 · 키워드 필터 적용 결과
  • columns — CODE_GROUP 선택 시 설명 헤더를 사용 화면 병기로 교체

주요 동작

  • openGroupMemo — 그룹 행이 있으면 수정, 없으면 CODE_GROUP 신규 등록(코드 프리필)
  • nextSortOrder — 그룹 내 최대값 + 10, 비어 있으면 10
  • save — 생성 시 새 그룹으로 선택 이동 후 전체 재로드
  • toggleActive — 비활성 → 활성은 즉시, 활성 → 비활성은 확인 모달
