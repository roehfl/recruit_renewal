구현 완료 수동 확인 대기 작성일: 2026-09-18

요약

지원현황 조회의 "엑셀 다운로드" 버튼이 컬럼 선택 모달을 열고, 체크한 항목(6그룹 44개, 기본 14개)만 엑셀로 내려받도록 구현했습니다.

컬럼 카탈로그는 백엔드 ApplicationExportColumn enum이 단일 출처이며, 모달은 카탈로그 조회 API로 체크박스를 그립니다. 셀 값은 페이지(1,000행)마다 선택 컬럼이 요구하는 섹션만 배치 조회해 만들고, 표기는 PDF와 같습니다.

화면 결함 2건(철회 라벨, "졸업년월"이 철회일시를 표시)을 함께 고쳤습니다. 변경 테스트 99건 통과, 프론트 type-check·build 성공. 실제 Excel·브라우저 확인은 환경 제약으로 수동 확인 항목으로 남았습니다.
