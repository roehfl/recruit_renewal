지원자 로그인 2차 인증(NICE) 구현

구현 완료 브라우저 실인증 미확인 작성일: 2026-10-08

요약

지원자 로그인에 NICE 본인확인을 2차 인증으로 붙였습니다. 로그인 클릭 시 NICE 팝업이 뜨고, 인증이 끝나면 POST /auth/login이 호출됩니다.

서버가 비밀번호 검증 직후 세션의 NICE 결과와 Applicant.ciHash를 대조하므로 API를 직접 호출해도 우회되지 않습니다. 임직원(LDAP)은 적용 대상이 아닙니다.

설정 recruit.nice.login-two-factor-enabled(기본 켜짐)로 켜고 끕니다. 변경 범위 백엔드 테스트와 프론트 타입 검사는 통과했고, 실제 NICE 팝업 흐름은 이 PC에서 확인할 수 없어 검증하지 못했습니다.
