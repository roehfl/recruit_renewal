Initialize Policy

  • Stage의 JobPosting에 속한 지원서만 조회한다.
  • SUBMITTED 지원서만 새 PENDING row 생성 대상이다.
  • DRAFT, WITHDRAWN은 skipped로 계산한다.
  • 이미 존재하는 stage_id + job_application_id row는 보존한다.
  • 재호출 시 누락분만 생성하므로 idempotent하게 동작한다.
  • Entity factory에서 Stage와 JobApplication의 JobPosting 일치 여부를 방어 검증한다.
