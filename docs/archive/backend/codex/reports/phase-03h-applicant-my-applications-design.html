Phase 03h-1 Applicant My Applications Design

Design Complete Generated: 2026-05-19

Executive Summary

This phase designs GET /applications/me, an applicant-only API for reading the current applicant's application list.

The recommended response is ApiResponse<PageResponse<MyApplicationResponse>> with fixed sorting by createdAt DESC, id DESC.

The list includes draft, submitted, and withdrawn applications, keeps closed postings visible, and includes only a compact announced-result summary.

No code, tests, security config, build config, YAML, schema, or runtime API was changed.

Validation And Policy

List Rules

  • Include DRAFT, SUBMITTED, and WITHDRAWN.
  • Closed postings remain visible.
  • Default sort is createdAt DESC, id DESC.
  • accepting is display data, not command authorization.

Result Summary Rules

  • Detailed results stay under /applications/{applicationId}/stage-results.
  • Summary includes count plus latest visible stage/result.
  • Visible means Stage.status == RESULT_ANNOUNCED || CLOSED.
  • READY and IN_PROGRESS rows are excluded.
