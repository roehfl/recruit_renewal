Phase 03h-3 Applicant Application Dashboard Design

Completed: Design Generated: 2026-05-19 Documentation Only

Executive Summary

This phase designs GET /applications/{applicationId}/dashboard, an applicant-only dashboard summary API for one owned application.

The endpoint is intended to sit between GET /applications/me and detailed section APIs, returning action flags, completion summary, missing-section hints, and compact announced-result summary.

No runtime API, Java source, tests, security config, validator, or schema was changed in this phase.

The recommended next phase is Phase 03h-4, a narrow read-only implementation of the dashboard summary API.

Result Summary

The dashboard result summary follows Phase 03h-2:

  • Only Stage.status == RESULT_ANNOUNCED || CLOSED is visible.
  • READY and IN_PROGRESS stages are excluded.
  • Latest result uses stageOrder DESC, stage.id DESC.
  • Detailed rows remain in GET /applications/{applicationId}/stage-results.
