신영증권 채용 Renewal Backend

Executive Summary

프론트엔드 개발 지원을 위한 최소 지원자 회원가입 API를 구현했습니다. POST /auth/applicants/sign-up 엔드포인트를 통해 지원자 계정을 생성할 수 있으며, 로그인은 기존 /auth/login을 통해 별도로 수행합니다.

⚠ Temporary API: ci 필드가 클라이언트 요청에서 직접 전달됩니다. 운영 환경에서는 NICE 본인인증 연동으로 교체해야 합니다.

Scope

✅ Implemented

  • POST /auth/applicants/sign-up endpoint
  • Request validation (loginId, password, name, phoneNumber, email, ci)
  • loginId / email / ciHash 중복 검사
  • Password BCrypt 인코딩
  • CI SHA-256 해싱
  • 응답에서 민감정보 제외
  • SecurityConfig permitAll 설정
  • GlobalExceptionHandler 매핑
  • Service 단위 테스트 6건
  • Controller 통합 테스트 4건

🚫 Out of Scope

  • NICE 본인인증 연동
  • 이메일 인증
  • 비밀번호 강도 정책
  • 이용약관 동의
  • CAPTCHA / Rate Limiting
  • SMS 인증

Validation & Business Rules

#Rule
1loginId: NotBlank, max 100, unique
2password: NotBlank, min 8, max 100, BCrypt encoded
3name: NotBlank, max 100
4phoneNumber: NotBlank, max 30
5email: @Email, max 255, optional (nullable)
6ci: NotBlank, max 255, SHA-256 hashed
7All string inputs trimmed
8Blank/whitespace email normalized to null
9loginId uniqueness checked
10email uniqueness checked (only when not null)
11ciHash uniqueness checked
12No auto-login or session creation
13Response excludes password, ci, ciHash, phoneNumber, email
