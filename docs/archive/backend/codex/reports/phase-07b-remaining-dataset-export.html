Phase 07b · 나머지 Dataset Export

Stage Results / Interviews / Interview Evaluations · list-parity xlsx (read-only)
Status: 완료  ·  Generated: 2026-06-01  ·  Slice: 07b (07a 인프라 재사용)

Executive Summary

Phase 07a의 export 인프라(ExcelExportWriter, 컬럼 spec, row cap, audit, 응답 factory)를 재사용해 나머지 3개 dataset의 list-parity xlsx download를 추가했다: stage results / interviews / interview evaluations.

각 export는 대응 admin list 엔드포인트의 기존 쿼리/서비스를 그대로 재사용해 필터·정렬· 파생값(면접 인원 카운트)을 동일하게 맞춘다(list-parity). materialize된 parity list에 공용 ExcelExportService가 row cap + writer를 적용한다. 모두 read-only, 새 entity/table/migration 없음. ci/ciHash/password 미포함, 평가 export는 읽기 전용(Phase 06 경계 유지).

진행 가능: 다음은 07c funnel statistics.

  • audit는 SLF4J 로그만(영속 ActivityLog backlog)

Design · list-parity via 기존 쿼리 재사용

07a applications는 unbounded global이라 count 선검증 + page-fetch projection을 썼다. 07b 3개 dataset은 stage/posting-scoped이고 대응 admin list가 이미 전체 materialize하므로, 기존 list 쿼리/서비스를 재사용해 parity를 보장하고 materialize된 list를 공용 헬퍼에 넘긴다(size > max면 writer 미호출).
