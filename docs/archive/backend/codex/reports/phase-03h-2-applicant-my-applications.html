Executive Summary

Implemented GET /applications/me for applicant-owned pageable application lists.

The response is ApiResponse<PageResponse<MyApplicationResponse>> and includes application basics, posting reception data, accepting, and compact announced-result summary.

The implementation keeps existing result detail, admin APIs, security configuration, schema, and notification behavior unchanged.

Targeted tests and full clean test --no-daemon completed successfully.

Validation Rules

Page Policy

  • page < 0 fails.
  • size <= 0 fails.
  • size > 100 fails.
  • Default sort is createdAt DESC, id DESC.

Result Summary Policy

  • Only RESULT_ANNOUNCED and CLOSED stages count.
  • READY and IN_PROGRESS are excluded.
  • No missing StageResult row is synthesized.
  • Latest result is by stageOrder DESC, stage.id DESC.
