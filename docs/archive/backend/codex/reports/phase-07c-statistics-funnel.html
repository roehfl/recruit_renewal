Phase 07c · 전형 Funnel 통계

공고 단위 모집단 P · stage별 7-bucket 분포 · 순차 통과 비율 · 분야별 dimension (read-only)
Status: 완료  ·  Generated: 2026-06-01  ·  Slice: 07c

Executive Summary

공고 단위 전형 funnel 통계 API를 추가했다. 모집단 P = 제출 이력(submittedAt != null) 코호트를 기준으로, 각 stage에서 P 전체를 raw 7-bucket(PASSED/FAILED/ABSENT/HOLD/PENDING/WITHDRAWN + 응답 전용 synthetic NO_RESULT)으로 분류(합=|P|)하고, 순차 통과 집합 S_k = S_(k-1) ∩ {stage k PASSED}로 funnelPassedCount·두 비율(누적/직전 전환)을 산출한다.

overall은 항상, dimension=POSITION이면 분야별(FK) 그룹 funnel을 추가로 반환한다. 모두 read-only, 새 entity/table 없음, 집계값만 노출(audit 없음). SCHOOL/CERTIFICATE 축은 미지원(400).

진행 가능: 다음은 07d Excel upload(StageResult).

Scope

구현

  • 모집단 P 코호트 + population 요약
  • stage별 7-bucket 분포(+NO_RESULT synthetic)
  • 순차 통과 집합 + 누적/직전 전환 비율
  • dimension=POSITION 분야별 breakdown

범위 밖

  • SCHOOL/CERTIFICATE 축(미지원 400, Phase 08~)
  • Excel upload(07d) · PDF(07e)
  • 평균/가중치/자동 합불, 비동기/캐싱

유의

  • in-memory 산출(공고 단위 bounded; 대형 공고는 GROUP BY 전환 여지)
  • topN은 free-text 축 대비 수용(POSITION 미적용)

Architecture

Controller → FunnelStatisticsService(@Transactional readOnly) → 공고 검증(404) + dimension 파싱(POSITION만, else 400) → stages(order) + cohort projection + stage-result projection → (stageId→(appId→status)) 인덱스 → computeCohort(overall) [+ positionId 그룹별]

새 entity/table/migration 없음. JobApplication/StageResult/Stage projection만 조회.
