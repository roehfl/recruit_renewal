# 드롭인 이미지

이 폴더에 아래 파일명을 그대로 넣으면 코드 수정 없이 화면에 적용된다.
파일이 없으면 기존 폴백(번들 `src/assets/images/logo.png` / 컴포넌트 배너)이 표시된다.

| 파일명 | 적용 위치 | 비고 |
| --- | --- | --- |
| `header-logo.png` | 지원자 헤더 좌측 로고 | `.svg` `.jpg` `.webp` 도 인식. 원본 비율을 유지하며 높이 40px(모바일 32px)로 표시된다. 텍스트 없이 이미지 하나만 나온다 |
| `main-banner.png` | 지원자 홈 메인 배너 | `.jpg` `.svg` `.webp` 도 인식. 가로 100%로 표시되므로 가로로 긴 이미지 권장 |

확장자는 표의 순서대로 탐색한다(로고: png → svg → jpg → webp, 배너: png → jpg → svg → webp).
