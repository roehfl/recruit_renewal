Phase 07a · Excel Export 인프라 + Applications Download

신영증권 채용 Renewal 백엔드 · Reporting 계층 첫 슬라이스(read-only)
Status: 완료  ·  Generated: 2026-06-01  ·  Slice: 07a (07b~07f 후속)

Executive Summary

Apache POI SXSSF 기반 Excel export 공통 인프라(ExcelExportWriter, 컬럼 spec 추상화, row cap, export audit)를 구축하고, 그 위에 applications 목록 xlsx download (연락처 컬럼 포함, global / per-posting 2개 엔드포인트)를 구현했다.

read-only이며 새 entity/table/migration이 없다. projection DTO를 Stream으로 읽어 SXSSF temp 파일을 만들고, controller가 스트리밍 후 temp 파일을 삭제한다. 모든 셀은 string cell로 쓰고 formula injection 위험 prefix를 escape한다. ci/ciHash/password는 절대 미포함.

진행 가능: 07b가 동일 인프라에 dataset spec만 추가하면 된다.

Architecture

흐름

Controller → ApplicationExportService(@Transactional readOnly) → countExportApplications (row cap 선검증) → ExcelExportWriter ← ExportRowSource(findExportApplications, page 1,000) → SXSSF temp file (finally dispose/close) → ExcelExportResponseFactory (StreamingResponseBody, 전송 후 temp 삭제)

데이터 소유

새 entity/table 없음. 전부 read-only. JobApplication + Applicant 연락처를 평탄 projection(ApplicationExportRow)으로 직접 조회하며, JPA entity/lazy를 writer에 넘기지 않는다.
