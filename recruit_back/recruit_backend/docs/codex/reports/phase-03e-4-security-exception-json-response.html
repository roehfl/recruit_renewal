Executive Summary

Phase 03e-4 adds Spring Security handlers for authentication and authorization failures.

Unauthenticated protected requests now return 401 with JSON ApiResponse.fail("Authentication is required.").

Authenticated users without authority now return 403 with JSON ApiResponse.fail("Access is denied.").

URL authorization rules, business exception handling, StageResult actor propagation, DTOs, and schema were not changed.

Architecture and Domain

Security Handler Structure

  • Handlers run before controller invocation.
  • Responses are serialized with ObjectMapper.writeValue(...).
  • ObjectProvider<ObjectMapper> reuses a mapper when available and avoids forcing a global mapper bean.
  • Messages are fixed strings for this phase.

Domain Impact

  • No entity relationship changed.
  • No DTO shape changed.
  • No service business logic changed.
  • Applicant result responses still hide actor and evaluation internals.

Validation and Business Rules

Authentication

  • Missing authentication returns 401.
  • Handled by AuthenticationEntryPoint.
  • Response body uses success=false.

Authorization

  • Insufficient authority returns 403.
  • Handled by AccessDeniedHandler.
  • Response body uses success=false.

Business Errors

  • Validation failures remain 400.
  • Not-found failures remain 404.
  • GlobalExceptionHandler remains responsible.
