Domain And Ownership

JobApplication owns ApplicationAttachment rows. A download is valid only when the attachment belongs to the requested application and the row is STORED. Applicant download also requires current-applicant ownership. Admin download verifies application existence and attachment scope under the existing admin authorization policy.
