Admin Layout Management

Executive Summary

Phase 05c implemented admin-facing layout management APIs for configuring the page arrangement of applicant application forms.

Three endpoints were added: layout read (with available sections metadata), layout save (replace-all semantics), and applicant-facing preview projection.

The service reuses Phase 05a layout domain entities, validators, and helpers. No existing source files were modified.

All endpoints are protected by the existing /admin/** security policy requiring ROLE_ADMIN or ROLE_RECRUIT_ADMIN.

Can move forward 13 service tests and 11 controller tests passed.

Validation / Policy

Editable Guard

  • editable=true only when posting is not CLOSED and now < receptionStartDateTime.
  • Save rejects CLOSED postings with "...무감된..." message (400).
  • Save rejects started reception with "...접수가 시작된..." message (400).
  • Read shows stale layouts as-is (no validation on read).

Layout Validation

  • Disabled sections cannot be placed.
  • Required sections must be placed.
  • BASIC_INFO must always be placed.
  • ApplicationFormConfig must exist for save.
  • Bean Validation: pages not empty, items not empty, valid types, valid sort orders.

Section Sources

  • BASIC_INFO: ALWAYS
  • EDUCATION to GAP_PERIOD: APPLICATION_FORM_CONFIG
  • QUESTION_ANSWER: QUESTION (active questions exist)
  • ATTACHMENT: ATTACHMENT_REQUIREMENT (requirement rows exist)

Available Sections

  • All 10 layout section types always appear in availableSections.
  • Each shows: enabled, required, placed, source.
  • Frontend uses this to show drag-and-drop section palette.

Remaining Issues

  • Limitation Admin endpoints do not provide per-field error mapping. The first validation error message is returned.
  • Limitation No audit trail for layout changes beyond BaseEntity createdBy/updatedBy fields.
  • Limitation Layout versioning and change history are not implemented.
  • Limitation Admin security uses path-based /admin/** policy. Per-posting ownership is not verified.

Next Phase
