Phase 03c-9-4: Admin Application Answer Lazy Read API

관리자 지원서 상세 화면에서 질문답변 영역을 별도 lazy API로 조회할 수 있도록 read-only endpoint를 추가했다.

Implemented

API

GET /admin/applications/{applicationId}/answers

Lazy Detail

Scope

관리자 상세 화면 전용이다. 목록, 검색, 통계 응답에는 답변 원문을 추가하지 않았다.

Deferred

Security TODO

원문 열람 권한, 마스킹, 감사 로그, export 포함 정책은 목록/검색/통계/리포트로 answerText를 넓히기 전 우선 보강한다.

Read Policy

조회 정책

  • applicationId 존재 여부만 확인한다.
  • DRAFT, SUBMITTED, WITHDRAWN 모두 조회 가능하다.
  • 공고 상태, 접수기간, form config flag와 무관하게 조회한다.
  • active JobPostingQuestion 기준으로 row를 만든다.
  • 정렬은 sortOrder ASC, id ASC다.
Privacy

원문 노출 정책

  • answerText는 관리자 상세 lazy 응답에만 포함한다.
  • 관리자 목록/검색/통계/root detail에는 포함하지 않는다.
  • 자유서술에는 민감정보가 포함될 수 있다.
  • 권한, 마스킹, 감사 로그는 후속 보안 Phase에서 처리한다.

Excluded In This Phase

  • Inactive question answers
  • Orphan answers outside the active question set
  • Revision/history display
  • Admin answer write command
  • PUT/DELETE endpoints
