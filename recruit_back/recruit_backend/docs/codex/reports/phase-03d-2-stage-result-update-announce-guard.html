Update Policy

RuleDecision
Editable Stage statusIN_PROGRESS only
READYinitialize only, result decision update rejected
RESULT_ANNOUNCED / CLOSEDgeneral update rejected
Allowed result statusesPASSED, FAILED, ABSENT, WITHDRAWN, HOLD
PENDING rollbackRejected
scorenullable, precision/scale deferred
commentnullable, max 2000 characters
decidedBySYSTEM temporary value

Bulk Policy

  • Bulk list must be present and non-empty.
  • Duplicate stageResultId fails.
  • All result ids must belong to the requested stage.
  • Any invalid item fails the whole transaction.
  • No partial success is allowed.

Announce Guard

StageResult stateAnnounce result
No rowsFail
Any PENDINGFail
All decided statusesAllowed

Decided statuses are PASSED, FAILED, ABSENT, WITHDRAWN, and HOLD.
