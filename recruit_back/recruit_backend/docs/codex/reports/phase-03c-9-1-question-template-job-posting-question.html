중요 정책

Template Snapshot

템플릿 기반 생성은 템플릿 값을 복사한 뒤 요청 override를 반영한다. 이후 템플릿 수정은 기존 공고 질문에 영향을 주지 않는다.

DRAFT Only

공고 질문 생성, 수정, 정렬, 비활성화는 JobPosting.status=DRAFT에서만 가능하다.

Soft Delete

삭제 command는 물리 삭제가 아니라 active=false 처리다. HTTP DELETE는 추가하지 않았다.

Length Limit

SHORT_TEXT <= 500, LONG_TEXT <= 5000. minLength는 선택이고 maxLength보다 클 수 없다.
