Phase 06c - 관리자 평가 조회

구현 완료 작성일: 2026-05-29

요약

Phase 06c는 관리자가 면접관 평가를 면접 / 단계 / 지원서 세 레벨에서 조회하는 API를 추가합니다.

면접 레벨 응답은 후보자별로 그룹화되고, 후보자마다 요약(제출 수, 총 평가자 수, 등급/추천 분포)을 포함합니다. 분포는 SUBMITTED 평가만 집계하고 DRAFT는 목록에는 포함하되 분포에서 제외합니다.

06a의 비정규화 FK(stage, jobApplication)를 활용해 단계/지원서 조회를 직접 인덱스 쿼리로 수행합니다. StageResult는 어디서도 참조/변경하지 않습니다.

API 목록

메서드경로권한응답
GET /admin/interviews/{interviewId}/evaluations ADMIN / RECRUIT_ADMIN AdminInterviewEvaluationResponse
GET /admin/stages/{stageId}/interview-evaluations ADMIN / RECRUIT_ADMIN List<AdminInterviewEvaluationResponse>
GET /admin/applications/{applicationId}/interview-evaluations ADMIN / RECRUIT_ADMIN List<AdminApplicationEvaluationResponse>

모든 응답은 ApiResponse<T>로 감쌉니다. 06b의 POST .../evaluations/initialize도 동일 컨트롤러에 유지됩니다.

응답 구조

면접/단계 레벨

AdminInterviewEvaluationResponse
 ├─ interviewId, interviewGroupName
 ├─ stageId, stageName, interviewStatus
 ├─ startDateTime, endDateTime
 └─ candidates[]
     ├─ candidateParticipantId
     ├─ applicationId, applicantName
     ├─ positionId, positionName
     ├─ summary
     │   ├─ submittedCount
     │   ├─ totalEvaluatorCount
     │   ├─ gradeDistribution{vg,gPlus,g,gMinus,f}
     │   └─ recommendationDistribution
     │       {strongYes,yes,neutral,no,strongNo}
     └─ evaluations[]
         ├─ evaluationId
         ├─ interviewerParticipantId, interviewerName
         ├─ status, grade, recommendation
         └─ comment, submittedAt

단계 레벨은 위 응답을 면접 단위로 묶은 리스트입니다.

지원서 레벨

List<AdminApplicationEvaluationResponse>
 (요소 = 면접 1건, 후보자 고정)
 ├─ interviewId, interviewGroupName
 ├─ stageId, stageName, interviewStatus
 ├─ startDateTime, endDateTime
 ├─ summary { ... }
 └─ evaluations[] { ... }

후보자가 고정되므로 candidate 그룹 없이 면접별 evaluations를 바로 보여줍니다.

집계 및 비즈니스 규칙

#규칙
1interview/stage/application 미존재 시 404
2면접 레벨은 후보자 participant 기준으로 그룹화(후보자 sort order 유지)
3submittedCount=SUBMITTED 수, totalEvaluatorCount=DRAFT+SUBMITTED 전체 수
4등급/추천 분포는 SUBMITTED만 집계, DRAFT는 목록에는 포함되나 분포 제외
5분포 DTO는 항상 5개 필드 모두 포함(없으면 0)
6관리자 view는 interviewerName 노출(면접관용 DTO는 타 면접관 비노출)
7단계/지원서 조회는 평가 행이 있는 면접만 노출(초기화 안 된 면접 제외)
8StageResult를 어디서도 참조/주입/변경하지 않음
