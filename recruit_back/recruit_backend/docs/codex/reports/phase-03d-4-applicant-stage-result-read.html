Phase 03d-4: Applicant StageResult Read

지원자가 본인 지원서의 발표 완료된 전형 결과만 조회하는 read-only API 구현 결과 보고서다. Updated: 2026-05-19

Completed

Phase Summary

GET /applications/{applicationId}/stage-results를 추가해 지원자 본인 발표 결과만 조회하도록 구현했다.

Read Only

API

POST, PUT, PATCH, DELETE는 추가하지 않았다. 조회 중 StageResult를 생성하거나 보정하지 않는다.

Limited

Exposure

score, comment, decidedBy, stageResultId는 지원자 응답에서 제외했다.

Executive Summary

  • 지원자 결과 조회는 기존 applicant 인증 패턴과 CurrentApplicantService를 사용한다.
  • Service는 applicantId + applicationId로 지원서 소유권을 검증한다.
  • DRAFT 지원서는 전형 결과 조회 대상에서 제외하고 비즈니스 예외로 처리한다.
  • SUBMITTED, WITHDRAWN 지원서는 RESULT_ANNOUNCED, CLOSED stage 결과만 조회할 수 있다.
  • resultAnnouncementDateTime은 표시용이며 예약 발표 guard는 구현하지 않았다.
