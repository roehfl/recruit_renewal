요약

07c funnel 통계에 SCHOOL dimension을 추가했다. 08c의 ApplicationEducation.schoolId(최종학력 매칭)로 코호트 P를 학교별로 분할하고(application 단위 distinct), 미매칭 + topN 초과 학교는 '기타'로 합산한다. 그룹별 funnel은 기존 computeCohort 재사용. CERTIFICATE는 master 부재로 미지원(400). 테스트 BUILD SUCCESSFUL.

항목규칙
학교 산정지원자 최종학력(가장 높은 EducationLevel) 1교의 schoolId. 동률이면 schoolId 보유 쪽 우선.

distinctapplication 단위(한 지원자는 정확히 한 그룹).
topN인원 desc·schoolId asc 정렬, 기본 10(최대 100, 0/null→10) 개별. 초과 학교 + 미매칭 + dangling = '기타' 1그룹.
응답기존 DimensionFunnelResponse(groupId, groupName, …) 재사용. SCHOOL=schoolId/schoolName, 기타=null/"기타".
